# docs

## What it does

Explains Burn as a whole: how the pieces fit, how to run it, and how to present it.

## How it works

Each component folder documents itself in its own README. The documents here cover what spans
components.

## Key files

- `architecture.md`: components, the four core flows (session, tool call, exit check, burn),
  data stores and least-privilege identity.
- `runbook.md`: deploy, run the demo, reset, checks, cost and teardown.
- `demo-script.md`: the four-minute demo, step by step, with fallbacks.

## How to test it

Every command in `runbook.md` is a `make` target; run `make help` to list them. `make e2e` checks
the containment flow described in `architecture.md` against a deployed stack.

## FAQ

**Where are the measured numbers?** `eval/RESULTS.md`, regenerated by `make eval`.
